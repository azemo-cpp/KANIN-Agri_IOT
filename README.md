# KANIN-Agri_IOT
Knowledge-driven Agriculture for Nurturing and Intelligent Nutrition System - IoT-based rice cultivation monitoring

## Overview
The K.A.N.I.N. System, a web-based crop growth monitoring system that utilizes IoT and Arduino-based technologies to enhance rice (*Oryza sativa*) cultivation.

## Materials List
### Main Hardware
